# Marketly

Marketly is a microservices-based e-commerce platform designed to provide
a scalable and reliable online shopping experience.

## Overview

Marketly allows users to browse and search for products, manage their
shopping cart, place orders, and complete payments through a set of
independent services.

The platform is designed around containerization, automated deployment,
scalability, monitoring, and infrastructure automation.
